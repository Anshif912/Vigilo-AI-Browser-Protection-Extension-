# Changelog

All notable changes to the **Vigilo IntelligenceOS** project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [3.5.0] - 2026-07-26

### Added
- **AI Threat Story Engine**: Generates human-friendly, jargon-free threat narratives (< 0.1 ms execution) explaining what a site is pretending to be, what data is targeted, why it was blocked, and potential impact.
- **Enterprise Cyber Mesh Gradient Background**: Multi-depth 6-layer cyber mesh background with deep space gradients (`#050608`), ambient glowing light orbs (`#8B5CF6`, `#3B82F6`), and subtle environmental radar sweep.
- **MagicBento Interaction Engine**: Apple VisionOS style card-relative cursor tracking, proximity perimeter border glow, 750px cursor spotlight, and click ripple feedback.

---

## [3.4.1] - 2026-07-25

### Added
- **Rule 21 (Browser Interstitial Detection)**: Automatic inspection of client-side DOM titles, page text, and vendor warning markers (Cloudflare, Google Safe Browsing, Microsoft SmartScreen, Firefox).
- **Free Hosting & Dynamic DNS Abuse Prevention**: Enhanced detection for abused cloud platforms (`repl.co`, `workers.dev`, `pages.dev`, `godaddysites.com`, `webflow.io`, `atwebpages.com`, `duckdns.org`).

---

## [3.4.0] - 2026-07-25

### Added
- **In-App Multilingual Localization System**: Added seamless in-app language switching across 6 languages: English (`en`), Tamil (`ta`), Hindi (`hi`), Kannada (`kn`), Telugu (`te`), and Malayalam (`ml`).
- **Language Selector Component**: Added floating language selector UI to Chrome Extension Popup, Warning Page, and Blocked Page.

---

## [3.3.0] - 2026-07-24

### Added
- **Autonomous Navigation & Tab Interception**: Chrome Extension automatically intercepts every tab navigation, sends URLs to backend analysis, and redirects High Risk / Critical sites to an inline blocked page.
- **PDF & JSON Threat Report Exporter**: Real-time generation of downloadable threat analysis reports directly from the blocked page.

---

## [3.0.0] - 2026-07-20

### Added
- **21-Rule Threat Fusion Engine**: Production release of the multi-heuristic risk engine combining brand typosquatting, subdomain obfuscation, entropy scoring, path impersonation, and TLS validation.
