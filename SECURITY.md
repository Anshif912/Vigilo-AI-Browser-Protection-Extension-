# Security Policy

## Supported Versions

The Vigilo team actively maintains security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 3.5.x   | :white_check_mark: |
| 3.4.x   | :white_check_mark: |
| < 3.4   | :x:                |

---

## Reporting a Vulnerability

Vigilo Security is committed to preserving user privacy and browser safety. If you discover a security vulnerability or threat intelligence bypass within Vigilo, please follow our responsible disclosure process.

### Preferred Reporting Method
**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, report vulnerabilities privately by emailing our security team at:
`security@vigilo-ai.org`

### Information to Include
- Detailed description of the vulnerability or threat detection bypass.
- Step-by-step instructions to reproduce the issue.
- Proof of Concept (PoC) URL or payload.
- Potential impact assessment.

---

## Privacy & Security Commitments

1. **Local-First Processing**: Vigilo evaluates URLs locally and via privacy-preserving backend analysis APIs.
2. **Zero Credential Capture**: Vigilo never captures, logs, or stores user passwords, form inputs, or authentication tokens.
3. **No Personal Data Telemetry**: Browsing history and user identities are never tracked or monetized.
